# Revv

> Revv (formerly RevvSales) is a document automation and electronic-signature platform for
> business paperwork — proposals, quotes, contracts and agreements — with templates, form-driven
> document generation, approval workflows, eSignature with audit trails, and a REST API. Revv was
> acquired by LegalZoom (announced 2022-10-17). As of 2026-08-14 the developer surface is
> withdrawn: no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server or agent card is
> published anywhere, the API reference host build.revv.so returns 404, and every
> www.revv.so/docs/* article returns 502. What is still live is the marketing site, which
> continues to advertise the API and its per-document price list.
